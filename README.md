# Analysis of Prostate Cancer Survival

• Developed a comprehensive tutorial guiding users through the full data science pipeline, including data curation, exploratory data analysis,
hypothesis testing, machine learning, and communicating results.
• Performed data validation and preprocessing on the genomic dataset for predictive modeling of survival outcomes using clinical attributes.
• Evaluated and compared machine learning models (Random Forest, Logistic Regression, SVM, Gradient Boosting) using metrics such as
confusion matrices, ROC curves, and precision-recall curves to optimize performance.
